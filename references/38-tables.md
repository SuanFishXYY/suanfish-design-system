# 📋 ref 38 · 表格规范

> *表格是密度最高的 UI 容器——每个像素都是数据的代价。*
>
> table-craftsman 主理表格容器结构（数据表/可编辑列表/虚拟滚动/表头操作/行操作）。表格里的图表归 ref 10 data-viz-engineer，空表格文案归 ref 31 empty-state-storyteller。哲学锚：Edward Tufte——让数据自己说话，去除 chartjunk。

## 1. 4 种典型规模

| 规模 | 行数 | 推荐方案 |
| --- | --- | --- |
| 小表 | ≤ 20 行 | 静态 DOM · 全量渲染 |
| 中表 | 20-200 行 | 分页 · 默认 20/页 |
| 大表 | 200-10k 行 | 虚拟滚动 · windowing |
| 巨表 | > 10k 行 | 后端分页 + 虚拟滚动 + 服务端筛选 |

## 2. 行高 / 密度

| 密度 | 行高 | 用途 |
| --- | --- | --- |
| 紧凑 | 36px | 数据密集型后台 |
| 标准 | 48px | 默认 |
| 宽松 | 56px | 移动端 / 触控 |

## 3. 列定义

```markdown
| 列 | 字段 | 类型 | 宽度 | 可排序 | 可筛 | 可编辑 |
| --- | --- | --- | --- | --- | --- | --- |
| 名称 | name | text | 200px | ✅ | ✅ | ❌ |
```

- 列宽必须可拖（用户的资产，不是设计师的）。
- 排序状态必须可视（不只是 hover 时显示）。
- 数字右对齐 / 文本左对齐 / 不要居中。

## 4. 交互

| 维度 | 选项 |
| --- | --- |
| 行点击 | 选中 / 进详情 / 无 |
| 行 hover | 高亮 / 无 |
| 行选择 | 单选 / 多选 / 无 |
| 列冻结 | 前 N 列冻结 |
| 列管理 | 显示/隐藏/重排 |
| 行操作 | 拖拽排序 / 批量操作 |

## 5. 表头操作

- 排序：点击列头切换 asc/desc/none，图标常驻显状态。
- 筛选：列头下拉筛选面板（复选/范围/搜索）。
- 列管理：列头右键或拖拽手柄，显示/隐藏/重排。
- 冻结：前 N 列粘性定位（`sticky left-0`）。

## 6. Tufte 三铁律

1. **去 chartjunk** — 不要 zebra stripe 全染 + 重边框 + 重内框，选一个。
2. **让数据排列说话** — 数字右对齐 / 文本左对齐 / 不要居中。
3. **数据墨水比最大** — 每个像素优先服务数据，不服务装饰。

## 7. 树形表格

- 折叠/展开：行首三角图标，子行缩进。
- 缩进：每级 `pl-4`，最多 5 级。
- 展开/折叠状态持久化（localStorage）。

```markdown
- 行 hover：<高亮/无>
- 行选择：<单选/多选/无>
- 列冻结：<前 N 列冻结>

### 性能
- 虚拟化阈值：<行数>
- 滚动条：<原生/自定义>
```

## 9. 不可妥协

- ✅ ≥ 100 行必须虚拟化。
- ✅ 列宽必须可拖。
- ✅ 排序状态必须可视。
- ❌ 表格里不嵌入第二层表格（用 master-detail 替代）。
- 滚动条用 `custom-scrollbar`（ref 01 §10）。
- 响应式：桌面表 + 移动卡片双形态（ref 33 §4）。
