# 🛡️ ref 42 · 品牌规范

> *Logo 大小、品牌色用法、品牌声调——一致性是品牌唯一的资产。*
>
> brand-keeper 是横切咨询者，任何 agent 出方案前可问"这个用法符合品牌吗"，只回 ✅/❌ + 一句理由。哲学锚：海德格尔——命名即占有，每一处品牌出现都在塑造用户认知。品牌是 marketing 资产，brand-keeper 是守护不是发明。

## 1. 品牌四件套（brand-keeper 的输入）

1. **Logo 使用规范** — 尺寸 / 留白 / 配色 / 反白 / 不可变形。
2. **品牌色** — 主色 / 辅色 / 不可改色调。
3. **品牌字体** — 标题字体 / 正文字体 / 数字字体。
4. **品牌声调** — 直白 / 温暖 / 正式 / 俏皮 中的哪一档（与 copy-writer 双声调匹配，ref 35）。

## 2. 品牌 5 条硬规则

1. **Logo 留白**：四周留白 ≥ Logo 高度 × 0.5。
2. **品牌色用量**：品牌主色 ≤ 30% 像素覆盖（避免审美疲劳）。
3. **品牌字体**：标题用品牌字体，正文用系统字体（性能）。
4. **品牌声调**：与 copy-writer 的"双声调"匹配（ref 35）。
5. **多品牌共存**：嵌入第三方品牌时必须分区域，不混色。

## 3. BRAND VERDICT 模板

```markdown
## 🛡️ 品牌判定

**问题**：<其他 agent 提出的方案点>
**判定**：✅ / ❌
**理由**：<一句话>
**修正建议**：<如果 ❌ 怎么改>
```

## 4. 触发 REJECT

- Logo 拉伸/变形/换色（除规定反白） → REJECT。
- 品牌色被用于非品牌强调（如普通按钮全染品牌色） → REJECT。
- 第三方品牌用得比自家品牌大 → REJECT。

## 5. 不可妥协

- ✅ 任何 agent 用到 Logo 必须问 brand-keeper。
- ✅ 任何 agent 用到品牌色必须问 brand-keeper。
- ❌ brand-keeper 不主动出方案——只把关。
- 品牌色与 ref 01 令牌系统协调：品牌主色进令牌表，不另起 HEX。

## 6. 联动

- 品牌声调 ↔ copy-writer 双声调（ref 35）。
- 品牌色 ↔ token-keeper 令牌（ref 01）。
- 品牌名不翻译 ↔ i18n-strategist（ref 43 不能翻译清单）。
- 付费墙品牌喧宾 ↔ rate-limit-communicator（ref 40）。
