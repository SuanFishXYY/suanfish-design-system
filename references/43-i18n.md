# 🌍 ref 43 · 国际化 i18n

> *英文 OK 按钮 24px，德文按钮要 96px——不为多语言留余地 = 不出海。*
>
> i18n-strategist 是横切咨询者，界面支持多语言时被咨询。哲学锚：维特根斯坦——语言的边界即世界的边界，每种语言重塑一次界面。i18n 不写翻译（copy-writer/翻译的活），只管布局与格式适配。

## 1. i18n 6 大决策点

| 决策点 | 中文默认 | 英文/德文 | 阿拉伯/希伯来 |
| --- | --- | --- | --- |
| **方向** | LTR | LTR | **RTL** |
| **字号** | 14-16px | 14-16px | 14-16px |
| **字宽倍数** | 1.0 | 1.4-1.8 | 1.2-1.5 |
| **行高** | 1.5 | 1.4 | 1.6 |
| **数字格式** | 1,000 | 1,000 / 1.000 | ١٬٠٠٠ |
| **日期格式** | 2025-01-15 | 01/15/2025 or 15/01/2025 | 视区 |

## 2. 文案空间预算

- 按钮：英文 ≤ 12 字符，预留 1.5 倍 → 中文 8 字符上限。
- 标题：英文 ≤ 30 字符，预留 1.4 倍 → 中文 21 字符上限。

中文是紧凑语言，外文膨胀 1.4-1.8 倍——容器必须预留，否则布局崩。

## 3. RTL 适配清单

- [ ] 布局使用 logical properties（`margin-inline-start` / `padding-inline-end`），不用 `margin-left`。
- [ ] 图标方向感（→ 在 RTL 应翻转，回退箭头方向反转）。
- [ ] 文字对齐（`text-align: start`，不用 `left`）。
- [ ] 表格列顺序（首列从右）。
- [ ] flex 方向（`flex-row` 在 RTL 自动反转，确认是否符合预期）。

## 4. 数字 / 日期 / 货币

- 使用 `Intl.NumberFormat` / `Intl.DateTimeFormat`。
- 不硬编码 `¥` `,` `.` 等符号。
- 货币走 `Intl.NumberFormat(locale, { style: 'currency', currency })`。

## 5. 不能翻译的清单

- 品牌名 / 产品名 / 专有名词（与 brand-keeper 协议，ref 42）。
- 法律实体名。
- 代码标识符（API 字段名、错误码）。

## 6. i18n 4 条硬规则

1. **不写 hardcode 字符串** — 全部走 i18n 系统（`t('key')`）。
2. **不假设字宽** — 容器用 `min-width` + `flex-grow`，不用固定 px。
3. **不嵌字串拼接** — 用占位符模板（`t('hello', { name })` → `Hello {name}`），不 `"Hello " + name`。
4. **不忘 RTL** — 至少预留方向反转的可能性（logical properties）。

## 8. 触发 REJECT

- 按钮硬编码宽度（如 `w-24` 24px 装不下德文） → REJECT。
- 表格列宽用 `px` 固定 → REJECT（改 `minmax(60px, 1fr)`）。
- 文案拼接（`"已选 " + n + " 项"`） → REJECT（用 i18n 占位符）。
