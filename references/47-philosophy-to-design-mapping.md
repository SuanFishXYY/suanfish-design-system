# 🧭 ref 47 · 哲学到设计的决策映射

## 一、七大矛盾 → UI 决策映射

ref 24 定义 D1-D7 矛盾。本节给每对矛盾"选 A 极 / 选 B 极 / 平衡"时的**具体 UI 决策**。

> **不选倾向 → R18 退回**：本节每对矛盾都必须选一极并给对方留位。**两端都站、不选倾向** = [ref 24 §五 R18](24-philosophy-dialectics.md) 病因级 REJECT（dialectician 触发，返回 BRIEF 要求选倾向）。本节映射的是"选了之后怎么落 UI"；"不选"不进映射，直接 R18。

### D1 简洁 ⟷ 可发现

| 倾向 | UI 决策 | 留位（给对方） |
| --- | --- | --- |
| 简洁 | 隐藏次级菜单（汉堡/抽屉）、默认折叠、快捷键优先 | 保留 `?` 帮助入口 / 命令面板（Cmd+K）兜底可发现 |
| 可发现 | 全展开导航、文字标签（非纯图标）、空状态引导 | 保留"专家模式"折叠入口 |
| D1 症状 | 一屏 ≥3 CTA = 强行可发现（非 R3·两端都站才触发 R18） | — |

### D2 自动化 ⟷ 用户掌控

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 自动化 | 自动保存、AI 预填、智能默认 | 保留"撤销/修改"出口（关键操作必有 undo · D2 强行自动症状） |
| 掌控 | 显式确认、手动保存、步骤分明 | 保留"自动模式"开关 |
| 边界 | 不可逆操作（删除/支付）**永不自动化** | 强制二次确认（ref 07 §7） |

### D3 个性化 ⟷ 一致性

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 个性化 | 个性化推荐、可调布局、主题选择 | 保留全局导航/字体规范/令牌系统不变（ref 01/42） |
| 一致性 | 标准布局、统一组件、固定信息架构 | 保留"偏好设置"入口给个性化 |
| 判据 | 个性化只动**内容层**，不动**结构层** | 结构一致是底线 |

### D4 引导 ⟷ 自由

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 引导 | Wizard 多步、进度条、Tooltip 引导 | 保留 skip 入口（onboarding >3 步必 skip · D4 强行引导症状） |
| 自由 | 空白画布、拖拽自由、无步骤 | 保留模板/示例库兜底新手 |
| 路径 | A 仪式强引导、G AI-native 自由 | 默认按路径倾向（ref 24 §四矩阵） |

### D5 数据 ⟷ 直觉

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 数据 | A/B 测试、埋点驱动、指标看板 | 保留设计师"否决权"出口（数据不知为何） |
| 直觉 | 设计师品味、品牌调性、情感判断 | 保留"用数据验证"入口 |
| 边界 | 合规/无障碍**不靠 A/B**（a11y 是底线非偏好） | ref 34 不可投票 |

### D6 即时 ⟷ 深思

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 即时 | 实时协作、流式输出、即时反馈 | 保留"异步评论/历史回看" |
| 深思 | 异步评审、批注、草稿 | 保留"@提及即时通知" |
| R16 | latency >2s 无 streaming/skeleton/progress → REJECT | — |

### D7 透明 ⟷ 神秘

| 倾向 | UI 决策 | 留位 |
| --- | --- | --- |
| 透明 | 显示思考过程（ref 39）、工具调用可见（ref 36）、引用标注（ref 41） | 保留"简化视图"折叠细节 |

## 二、五大规律 → 时代对齐决策

ref 25 定义 L1-L5 律。本节给每条律"顺律/逆律"时的**设计决策**。

### L1 复杂度螺旋（简单→复杂→重新简化）

| 阶段 | 设计决策 |
| --- | --- |
| Simple | 直接能用，别过早抽象 |
| Complex | 功能堆砌期，准备收口 |
| Simplified-as-different | 表面简化但内核复杂（AI 黑箱），别回退"专业版"陷阱 |
| R13 | Complex 阶段拒不收口 / Simplified 阶段强行回 Complex → REJECT |

### L2 抽象具象交替（file→folder→tag→vector→agent）

| 时代 | IA 决策 |
| --- | --- |
| 2024+ | 默认 agent/vector 组织（信息找人），folder 为辅 |
| R14 | 核心交互还在"新建文件夹" → 强提醒；tag→folder 退化须强业务理由 |

### L3 控制权下移（开发者→用户→AI）

| 决策 | 规则 |
| --- | --- |
| AI 该接管 | 可撤销/可回看的决策（推荐、预填、排序） |
| AI 不该接管 | 不可逆操作（删除/支付/医疗剂量）—— 逆方向越权 |
| R15 | G 路径坚持 6 层确认流 / 让 AI 决定不可逆 → REJECT |
| 例外 | 医疗/金融关键操作豁免 L3，须显式声明 |

### L4 反馈循环缩短（batch→daily→real-time→predictive→preemptive）

| 决策 | 规则 |
| --- | --- |
| 默认 | 流式/skeleton/progress（latency >2s 必有） |
| R16 | "请等待 5 分钟"非异步流 → REJECT（除非物理限制） |
| 反向 | batch 业务（财务月结）强 real-time = 无意义压力 |
| 例外 | 法律合规文档须留思考时间，豁免 L4 |

### L5 模态融合（text→multimedia→multimodal→synesthetic）

| 决策 | 规则 |
| --- | --- |
| 默认 | 核心流程配图标/动效/反馈音（非纯文字） |
| R17 | 2024 年核心流程还"纯文字按钮+文字反馈" → REJECT（移动端尤其） |
| 反向 | 信息密度场景（dashboard 数字）强加视频/语音 = 注意力浪费 |
| 例外 | 极简书写工具（iA Writer）单模态是核心价值，豁免 L5 |

## 三、矛盾 × 规律 × 路径 三维决策

dialectician 命名矛盾、historian 定位时代、futurist 预测漂移，三者交汇成**单一 UI 决策**。

```
例：BRIEF = "AI 帮用户自动分类邮件"
  ├ 矛盾 (ref 24): D2 自动化⟷掌控
  ├ 倾向: 自动化（AI 分类）
  ├ 留位: 用户可改分类规则 + 撤销
  ├ 规律 (ref 25): L3 控制权下移 → AI 该接管（可回看）✓
  ├ 路径 (ref 24 §四): G AI-native 默认掌控，但分类可撤销 → 通过
  ├ 历史 (ref 26): E7 AI-native 时代 ✓
  └ 决策: 自动分类 + 规则可编辑 + 撤销 + 分类理由可见(透明 D7)
```

三维对齐 = 决策有底层逻辑；三维冲突 = dialectician 强提醒，须 BRIEF 显式选倾向。

## 四、不可投票的底线

哲学辩证不是什么都可投票。以下**不论 D 矛盾倾向如何，不可妥协**：

| 底线 | 依据 | 不可投票原因 |
| --- | --- | --- |
| a11y 合规 | ref 34 | 弱势用户主权，非偏好 |
| 错误透明 | ref 31 | 用户有权知道发生了什么 |
| 不可逆操作确认 | ref 07 | 数据主权 |
| 令牌系统一致 | ref 01 | 视觉一致性根基 |
| 品牌核心资产 | ref 42 | 品牌一致性 |

D5 数据⟷直觉下，a11y 不靠 A/B——a11y 是底线非偏好。
